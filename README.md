# Network Infrastructure Project

## Project Overview

This project involved designing, configuring and testing a network infrastructure environment using core networking concepts and technologies.

The project focused on IP addressing, subnetting, routing, DHCP configuration, network connectivity and troubleshooting.

It provided practical experience in planning networks and configuring devices to allow communication between different hosts and network segments.

## Project Objectives

The main objectives were to:

- Design a functional network topology
- Develop an appropriate IP addressing scheme
- Subnet networks according to host requirements
- Configure routers and network devices
- Configure DHCP for automatic IP address allocation
- Establish communication between different networks
- Test network connectivity
- Identify and troubleshoot network problems

- Cisco Packet Tracer

- Subnetting
- DHCP

## Network Design

The network was designed to connect multiple devices and network segments while maintaining an organized IP addressing structure.

The design included:

- Routers
- Switches
- Client computers
- Multiple network segments
- DHCP services
- Default gateways
- IP addressing and subnet masks

## IP Addressing & Subnetting

IPv4 addressing and subnetting were used to divide the available network space into smaller networks.

This involved:

- Determining host requirements
- Calculating subnet masks
- Identifying network addresses
- Identifying usable host ranges
- Determining broadcast addresses
- Assigning gateway addresses
- Allocating IP addresses to network devices

Variable Length Subnet Masking (VLSM) was also used to allocate address space efficiently based on the number of hosts required by different network segments.

## Routing

Routing was configured to enable communication between separate networks.

Router interfaces were configured with appropriate IP addresses and network settings to allow traffic to move between different network segments.

Connectivity between networks was then tested to verify successful routing.

## DHCP Configuration

DHCP was configured to automatically provide client devices with network configuration information.

This included:

- IP addresses
- Subnet masks
- Default gateways
- DNS information

DHCP pools were configured according to the requirements of the different network segments.

## Network Testing

Several methods were used to verify network functionality, including:

- `ping`
- `ipconfig`
- Checking interface configurations
- Testing communication between hosts
- Testing communication between different networks
- Verifying DHCP address allocation
- Checking gateway connectivity

## Network Troubleshooting

During the project, network connectivity issues were diagnosed by checking:

- Incorrect IP addresses
- Subnet masks
- Default gateway configuration
- Router interfaces
- DHCP configuration
- Physical and logical connections
- Routing configuration
- Device connectivity

The troubleshooting process helped develop a systematic approach to identifying and resolving network problems.
